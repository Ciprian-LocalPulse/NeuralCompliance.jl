API Reference

Core Types

NeuralCompliance.RiskLevel — Type
RiskLevel

Ordinal classification of the severity of a compliance violation, loosely modeled on operational risk tiers used in regulated financial environments (e.g. Basel-style risk buckets).

source
NeuralCompliance.AbstractConstraint — Type
AbstractConstraint

Supertype for all mathematical constraints that a model's behavior can be checked against. Concrete subtypes must be usable with check_constraint.

source
NeuralCompliance.BoundConstraint — Type
BoundConstraint{T<:Real} <: AbstractConstraint

Requires that every component of a model's output lies within [lower, upper]. Typically used to certify, e.g., that a credit-risk score or a probability output can never leave a mandated range.

source
NeuralCompliance.LipschitzConstraint — Type
LipschitzConstraint <: AbstractConstraint

Requires that the estimated local Lipschitz constant of the model over a region not exceed max_constant. A tight Lipschitz bound is a proxy for output sensitivity to small input perturbations, which is directly relevant to adversarial robustness and to "explainability under perturbation" requirements common in regulated ML deployments.

source
NeuralCompliance.MonotonicityConstraint — Type
MonotonicityConstraint <: AbstractConstraint

Requires that the model's output be monotonic (increasing or decreasing) with respect to a given input coordinate. Common in underwriting and pricing models where regulators require, e.g., that predicted default probability never decreases as debt-to-income increases.

source
NeuralCompliance.ComplianceResult — Type
ComplianceResult

Outcome of checking a single AbstractConstraint against a model. Immutable record intended to be serialized into audit trails.

source

Interval Arithmetic & Bound Propagation

NeuralCompliance.Interval — Type
Interval{T<:Real}

A closed real interval [lo, hi]. Supports elementwise arithmetic needed for sound bound propagation through linear layers and common activations.

source
NeuralCompliance.width — Function
width(i::Interval) -> Real

Returns the width (hi - lo) of an interval.

source
NeuralCompliance.midpoint — Function
midpoint(i::Interval) -> Real

Returns the midpoint ((lo + hi) / 2) of an interval.

source
NeuralCompliance.relu — Function
relu(i::Interval) -> Interval

Sound elementwise ReLU of an interval: [max(lo,0), max(hi,0)].

source
NeuralCompliance.sigmoid_bound — Function
sigmoid_bound(i::Interval) -> Interval

Sound elementwise sigmoid of an interval. Sigmoid is monotonic, so the image of an interval under sigmoid is exactly [sigmoid(lo), sigmoid(hi)].

source
NeuralCompliance.tanh_bound — Function
tanh_bound(i::Interval) -> Interval

Sound elementwise tanh of an interval (tanh is monotonic).

source
NeuralCompliance.DenseLayer — Type
DenseLayer

A single affine layer y = W*x + b followed by an elementwise activation function act (must accept and return Interval or Vector{<:Real} uniformly, e.g. relu, sigmoid_bound, identity).

source
NeuralCompliance.propagate_bounds — Function
propagate_bounds(layers::Vector{<:DenseLayer}, input::AbstractVector{<:Interval})
    -> Vector{<:Interval}

Propagates a vector of per-coordinate input intervals through a stack of DenseLayers using sound interval arithmetic, returning the certified output interval vector.

This is the core primitive used to certify BoundConstraints: if the certified output interval satisfies the required bound, the model is provably compliant for every point inside the input region – not merely for observed samples.

source
NeuralCompliance.affine_propagate — Function
affine_propagate(W, b, x::AbstractVector{<:Interval}) -> Vector{<:Interval}

Sound propagation of an interval vector x through the affine map y = W*x + b, using the classical center-radius decomposition:

y_i = c_i ± r_i,  where c = W*midpoint(x) + b,  r = |W|*radius(x)

This is the numerically preferred formulation (avoids catastrophic cancellation relative to naive lo/hi products) and is O(n*m) for a dense m x n weight matrix, matching ordinary matrix-vector cost.

source
NeuralCompliance.certify_output_bounds — Function
certify_output_bounds(layers, input_lo, input_hi) -> Vector{Interval}

Convenience wrapper: builds per-coordinate input intervals from elementwise lower/upper vectors and propagates them through layers.

source

Constraint Checking

NeuralCompliance.check_constraint — Function
check_constraint(c::BoundConstraint, output::Interval) -> ComplianceResult

Certifies a BoundConstraint using a sound output interval (typically produced by propagate_bounds). Because interval bound propagation is conservative, passing this check is a guarantee that holds for every input in the certified input region, not just for sampled points.

source
check_constraint(c::BoundConstraint, outputs::AbstractVector{<:Real}) -> ComplianceResult

Empirical (sample-based) variant. Weaker guarantee than the interval form – only certifies the sampled points – but useful for quick smoke checks and for constraints where no closed-form bound propagation rule exists.

source
check_constraint(c::LipschitzConstraint, estimated_constant::Real) -> ComplianceResult

Certifies a LipschitzConstraint against an estimate produced by estimate_lipschitz.

source
check_constraint(c::MonotonicityConstraint, xs::AbstractVector, ys::AbstractVector{<:Real}) -> ComplianceResult

Certifies monotonicity along a 1-D sweep of the input coordinate c.input_index, where xs are the swept coordinate values (sorted ascending) and ys are the corresponding scalar model outputs.

source

Robustness & Stress Testing

NeuralCompliance.StressTestReport — Type
StressTestReport

Summary statistics of a Monte Carlo adversarial stress test.

source
NeuralCompliance.adversarial_stress_test — Function
adversarial_stress_test(f, x0, epsilon; n_samples=1000, norm=:linf, rng=Random.default_rng(),
                         tolerance=Inf) -> StressTestReport

Probes f in an epsilon-ball around x0 using random sampling and reports how much the (scalar or vector) output can move.

Arguments

  • f: a function f(x::Vector{Float64}) -> Union{Real, Vector{<:Real}}.
  • x0: nominal input point (Vector{Float64}).
  • epsilon: perturbation radius.
  • n_samples: number of Monte Carlo perturbations to draw.
  • norm: :linf (box perturbation) or :l2 (ball perturbation).
  • tolerance: if the maximum observed output deviation exceeds this value, the report is marked robust = false. Defaults to Inf (report statistics only, no pass/fail judgement).

This is a randomized, unsound procedure: it can miss worst-case points that a targeted (e.g. gradient-based) adversary would find. It is intended as a fast, dependency-free triage tool, complementary to – not a replacement for – the certified bounds in propagate_bounds.

source
NeuralCompliance.estimate_lipschitz — Function
estimate_lipschitz(f, x0, epsilon; n_samples=500, rng=Random.default_rng()) -> Float64

Estimates a local Lipschitz constant of f around x0 via finite differences over randomly sampled perturbation directions:

L̂ = max_i ||f(x0 + δᵢ) - f(x0)|| / ||δᵢ||

This is a lower bound on the true local Lipschitz constant (a random search cannot overestimate the true supremum), so it should be treated as a diagnostic signal, not a certified upper bound. For certified bounds use interval-based propagation where the architecture is known.

Audit & Provenance

NeuralCompliance.AuditReport — Type
AuditReport

A complete compliance audit for a single model, aggregating one ComplianceResult per checked constraint.

source
NeuralCompliance.generate_report — Function
generate_report(model_name, model_data, results) -> AuditReport

Assembles an AuditReport from a list of ComplianceResults, fingerprinting model_data for provenance.

source
NeuralCompliance.to_markdown — Function
to_markdown(report::AuditReport) -> String

Renders an AuditReport as a Markdown compliance summary, suitable for direct inclusion in a model-risk documentation package.

source
NeuralCompliance.to_json — Function
to_json(report::AuditReport) -> String

Renders an AuditReport as a minimal, dependency-free JSON string (no external JSON package required, keeping the framework's dependency footprint small for security-sensitive deployments).

source
NeuralCompliance.write_report — Function
write_report(report::AuditReport, path::AbstractString; format=:markdown)

Writes the audit report to disk in :markdown or :json format, inferred from path's extension if format is not given explicitly.

source
NeuralCompliance.model_fingerprint — Function
model_fingerprint(data) -> String

Computes a stable SHA-256 hex digest of arbitrary model data (e.g. a tuple of weight matrices) for provenance tracking. Two audit reports generated from bit-identical model parameters will carry identical fingerprints, which is the basis for detecting undisclosed model drift between audit cycles.

source
NeuralCompliance.overall_passed — Function
overall_passed(report::AuditReport) -> Bool

Returns true if every constraint check in report passed.

source
NeuralCompliance.highest_failing_risk — Function
highest_failing_risk(report::AuditReport) -> Union{RiskLevel,Nothing}

Returns the highest RiskLevel among failing checks, or nothing if the report is fully compliant.

NeuralCompliance.interval_tightness — Function
interval_tightness(i::Interval) -> Real

Returns width(i), a simple proxy for how "tight" (informative) a certified bound is. Wider certified intervals indicate either a large input region or accumulated conservatism in bound propagation.

source
NeuralCompliance.risk_score — Function
risk_score(results::Vector{ComplianceResult}) -> Float64

Aggregates a batch of compliance results into a single scalar risk score in [0, 1], weighting failures by risk level. 0.0 indicates a fully compliant model; higher scores indicate more severe or more numerous violations.

Orchestration

NeuralCompliance.run_compliance_audit — Function
run_compliance_audit(model_name, layers::Vector{<:DenseLayer},
                      input_lo, input_hi, constraints::Vector{<:AbstractConstraint};
                      model_data=layers) -> AuditReport

End-to-end convenience entry point for the certified-bounds workflow: propagates [input_lo, input_hi] through layers, checks every BoundConstraint in constraints against the certified output interval(s), and returns a fingerprinted AuditReport.

Non-BoundConstraint entries in constraints are skipped with a @warn, since they require different evidence (see adversarial_stress_test and the MonotonicityConstraint sweep workflow in the documentation).
